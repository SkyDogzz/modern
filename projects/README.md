# Project Scaffolds

Only projects that require supplied code or broken fixtures are scaffolded here.
Create the remaining project directories when beginning them.

The scaffolds intentionally omit completed implementations:

- `01-compile-run-diagnostics`: first compilable source file;
- `04-integer-conversion-lab`: expected compile-fail narrowing example;
- `13-compilation-linking-lab`: missing-definition linker fixture;
- `16-lifetime-storage-visualizer`: supplied thread-local observation example;
- `43-type-erased-command-system`: structural guidance without implementation.

Copy a scaffold into a learner worktree or branch before modifying it. Keep the
curriculum support version unchanged so later learners receive the same starting
point.
